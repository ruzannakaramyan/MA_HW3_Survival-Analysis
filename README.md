# Customer Churn Survival Analysis

## 📝 Description
This homework analyzes customer churn data using survival analysis techniques to:
- Predict customer lifetime value (CLV)
- Identify high-risk customers
- Calculate optimal retention budgets

## 📂 Files
- `data/telco.csv` - Raw dataset
- `MA_HW3.Rmd` - R code and documentation
- `Report.pdf` - Final compiled report

## ▶️ How to Run
